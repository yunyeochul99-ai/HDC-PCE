설비보전 점검 앱 (오프라인 설치형)

[구성] index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png
다섯 파일을 같은 폴더에 두고 함께 올려야 합니다.

[1] 올리기 (한 번만, HTTPS 필요)
- 가장 쉬운 방법: Netlify Drop(app.netlify.com/drop)에 이 폴더를 끌어다 놓기
- 또는 GitHub Pages, 사내 웹서버(HTTPS) 중 편한 곳
- 설치 후에는 인터넷 없이 실행됩니다.

[2] 각 담당자 폰에 설치 (신호 되는 곳에서 1회)
- 아이폰: Safari로 주소 열기 -> 공유 -> 홈 화면에 추가
- 안드로이드: Chrome으로 주소 열기 -> 메뉴(⋮) -> 앱 설치 / 홈 화면에 추가
- 홈 화면 아이콘으로 한 번 실행해 두면 이후 신호 없이도 열립니다.

[3] 기록 모으기 (기록 탭)
- 담당자: "백업 보내기"를 누르면 공유창이 뜹니다. 카카오톡, 메일 등으로 관리자에게 보냅니다.
  (공유창이 안 뜨면 "백업 글 복사"를 누르고 카톡 메시지에 붙여넣어 보냅니다.)
- 관리자: 받은 파일은 "파일로 가져오기", 받은 글은 "붙여넣어 가져오기" 후 "붙여넣은 내용 합치기"를 누릅니다.
  중복은 자동으로 제외됩니다.
- 엑셀 정리용은 "CSV 보내기"

[주의]
- 기록은 각 폰에만 저장됩니다. 브라우저 데이터를 지우면 사라지니 주기적으로 백업하세요.
- 앱을 수정해 다시 올릴 때는 sw.js 첫 줄의 현재 버전 문자열(maint-v10)을 maint-v11으로 바꿔야 폰에 반영됩니다.

[사진 첨부]
- 점검·일일점검 화면의 "📷 사진" 버튼으로 항목별로 사진을 여러 장(최대 5장) 첨부할 수 있습니다 (자동 압축, ✕로 개별 삭제).
- 사진은 서버 Storage(photo 버킷)에 저장되고 기록에는 경로만 남아 폰 용량을 아낍니다.
- 예전 기록에 폰에 저장된 사진(base64)이 있으면 동기화 때 서버로 자동 이전합니다.
- 사진 보기는 인터넷 연결 시 가능합니다.
- 기록 탭의 "📷 사진 일괄 저장"으로 전체 점검 사진을 ZIP 파일 하나로 내려받습니다.
- CSV에는 사진 개수와 주소(URL) 열이 들어갑니다. 사진 파일 자체는 "📷 사진 일괄 저장"으로 받습니다.

[Supabase 연동 (자동 공유)]
- 서버 설정: supabase-setup.sql을 Supabase의 SQL Editor에 붙여넣고 Run (먼저 1회, 사진 버킷 생성 포함)
- Authentication 설정에서 이메일 확인(Confirm email)을 꺼야 가입이 바로 완료됩니다.
- 관리자가 앱에서 먼저 가입한 뒤, SQL 파일 맨 아래 주석 SQL의 '내아이디'를 바꿔 실행하면 관리자로 지정됩니다.
- 다른 담당자는 앱에서 가입하면 승인 대기 상태가 되고, 관리자가 기록 탭의 "가입 승인"에서 승인합니다.
- 기록은 먼저 폰에 저장되고, 인터넷이 되면 자동으로 서버와 합쳐집니다.
